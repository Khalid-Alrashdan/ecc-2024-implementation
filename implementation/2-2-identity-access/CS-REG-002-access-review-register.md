# سجل المراجعة الدورية لهويات الدخول والصلاحيات

## الغرض

يوثّق هذا السجل نتائج المراجعة الدورية لهويات الدخول والصلاحيات في شركة نَسَق للحلول الرقمية، ويُعدّ دليل التزام بالضابطين 2-2-3 و 1-9-5، ويُعدّ مخرَجاً من حزمة العمل WP-03.

## بيانات المراجعة

| البند | البيان |
|---|---|
| رقم المراجعة | AR-1448-001 |
| نوع المراجعة | المراجعة الأولى الشاملة — نطاق كامل |
| الفترة المشمولة | جميع الحسابات القائمة حتى ١ ربيع الأول ١٤٤٨هـ |
| الجهة المنفّذة | وحدة الحوكمة والمخاطر والالتزام بمشاركة المديرين المباشرين |
| المرجعية | سياسة إدارة هويات الدخول والصلاحيات CS-POL-002 · معيار الحسابات ذات الصلاحيات الهامة CS-STD-003 |
| المراجعة القادمة | نصف سنوية |
